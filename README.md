# Zakia Home website

Responsive static website for zakiahome.com.

## Files
- `index.html` — page content and structure
- `styles.css` — full responsive visual design
- `script.js` — mobile menu, scroll reveal, newsletter interaction

## Publish on GoDaddy
Upload the three website files to the root folder of your hosting account (usually `public_html`).
Make sure `index.html` is in the root.

## Before launch
1. Replace `hello@zakiahome.com` if you use another email.
2. Connect the newsletter form to Mailchimp, Klaviyo, Shopify, GoDaddy Email Marketing, or another service.
3. Add real product photos when available.
4. Replace the temporary built-in Zakia symbol with the final logo file if desired.
5. Add legal pages (Privacy, Terms, Shipping/Returns) before taking online payments.

The page currently works with no images: all visuals are created in CSS so it loads quickly and can be previewed immediately.
